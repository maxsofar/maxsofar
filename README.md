# Hey, I'm Max 👋
CS grad from the Technion · Haifa · Building things that look good and work close to the metal.

I got into programming because I genuinely enjoy it — the late-night debugging sessions, the satisfaction when something finally clicks, doing assignments early because I actually want to, not because I have to. I like working close to the metal and I like making things look good. Both, ideally at the same time.

## What I've built

| Project | What it is | Stack |
|---|---|---|
| 📱 [Academic Resource Navigator](https://github.com/maxsofar/SBapp) | Native iOS app inspired by a discontinued university resource site. Built from scratch to explore SwiftUI — added my own features and preferences throughout. | Swift, SwiftUI |
| 🚀 [Rocket Alerts Map](https://github.com/maxsofar/rocket-alerts-map) | Real-time browser map of Israeli rocket alerts. The alerts API didn't allow direct browser requests (CORS), so I wrote a Python proxy deployed on Vercel — with a fallback chain and live connection status indicator. | Python, Flask, JS, Vercel |
| 🧾 [Invoicing Tool](https://github.com/maxsofar/Accounting) | Web invoicing app — existing tools don't run on Mac and look terrible. Wanted to see how fast I could build something usable and clean. | Flask, Python, HTML/CSS |
| 🎮 [Terminal RPG](https://github.com/maxsofar/234124---ex4) | Card game engine from my first OOP course. Input is a text file defining the deck, players, and moves — the program runs the game and logs every result. Built around inheritance, polymorphism, factories, and singletons. Done solo, before AI was part of the workflow. | C++ |
| ⚙️ [DFS in Assembly](https://github.com/maxsofar/dfs-x86-assembly) | Depth-first search in x86 Assembly with limited available registers. Started as a mandatory assignment, became an optional bonus after many students couldn't complete it. I did. | Assembly |
| 📅 [DataSetGo](https://play.google.com/store/apps/details?id=com.technion.android.data_set_go) | Trip planning app — published on the Play Store as part of a university course. I drove most of the feature work: sorting/filtering, maps integration, calendar scheduling, search suggestions, and a day view. Also built a solo prototype before the project started to scope what was achievable. Got 99. | Flutter, Dart |
