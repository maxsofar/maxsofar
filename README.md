# Hey, I'm Max 👋
CS grad from the Technion · Haifa · Building things that look good and work close to the metal.

I got into programming because I genuinely enjoy it — the late-night debugging sessions, 
the satisfaction when something finally clicks, doing assignments early because I actually 
want to, not because I have to. I like working close to the metal and I like making things 
look good. Both, ideally at the same time. My favorite kind of project is seeing an obvious 
real-world problem and building the solution — like watching someone manage a whole 
logistics operation on paper and knowing exactly what needs to exist.

## What I've built

| Project | What it is | Stack |
|---|---|---|
| 🏭 Logistics Management System | Full-stack logistics dashboard built for a real distribution client. FIFO stock reservation engine, adaptive demand forecasting (CV + lead time), PostgreSQL views with multi-level CTEs, bilingual Hebrew/English UI with RTL, mobile layout. Deployed on Vercel, actively in production. | Next.js, TypeScript, Tailwind, Supabase |
| 📱 [Academic Resource Navigator](https://github.com/maxsofar/SBapp) | Native iOS app built after the university's own resource site went down. Fetches a live course list from GitHub-hosted CSV, scrapes lesson links with SwiftSoup, and supports favorites, completion tracking, and home screen quick actions. | Swift, SwiftUI |
| 📅 [DataSetGo](https://play.google.com/store/apps/details?id=com.technion.android.data_set_go) | Trip planning app — published on the Play Store as part of a university course. I drove most of the feature work: sorting/filtering, maps integration, calendar scheduling, search suggestions, and a day view. Also built a solo prototype before the project started to scope what was achievable. Got 99. | Flutter, Dart |
| 🚀 [Rocket Alerts Map](https://github.com/maxsofar/rocket-alerts-map) | Real-time map of Israeli rocket alerts. The browser can't call the Oref API directly (CORS), so I wrote a Python proxy deployed on Vercel. The app tries three sources in order — local proxy, Vercel, then the official URL — and shows live connection status. | Python, JS, Vercel |
| 🧾 [Invoice Manager](https://github.com/maxsofar/invoice-manager) | Web invoicing app — existing tools don't run on Mac and look terrible. Client/order management, AJAX updates, server-side PDF generation, and Hebrew/English RTL support. | Flask, Python, SQLite |
| 🎮 [Mtmchkin](https://github.com/maxsofar/mtmchkin) | Turn-based card game engine from my first OOP course. Input is a deck file and player roster — the engine runs rounds, tracks state, and logs every encounter. Built around polymorphic card/player hierarchies and factory pattern. Done solo. | C++ |
| ⚙️ [DFS in Assembly](https://github.com/maxsofar/dfs-x86-assembly) | Depth-first search in x86 Assembly with limited available registers. Started as a mandatory assignment, became an optional bonus after many students couldn't complete it. I did. | Assembly |
